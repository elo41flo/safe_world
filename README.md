# 🌍 Safe World - Réseau Social Sécurisé

![Version](https://img.shields.io/badge/version-1.0.0-blue)
![React](https://img.shields.io/badge/React-19-61dafb)
![Vite](https://img.shields.io/badge/Vite-8.0-646cff)

**Safe World** est une application de réseau social conçue pour offrir un environnement numérique sécurisé et personnalisable. Ce projet a été réalisé dans le cadre d'un titre professionnel de Développeur Web et Web Mobile.

---

## 🚀 Fonctionnalités Clés

- **Gestion de l'Authentification** : Inscription et connexion sécurisées.
- **Système de Thèmes Dynamiques** : 4 ambiances personnalisables (Clair, Sombre, Tech, Cyber).
- **Fil d'Actualité (Feed)** : Création et visualisation de publications.
- **Espace Parental** : Fonctionnalités dédiées à la sécurité des plus jeunes.
- **Notifications en Temps Réel** : Système de pastilles (badges) pour les messages et interactions non lus.
- **Profil Utilisateur** : Personnalisation des informations et suivi de l'activité.

---

## 🎨 Personnalisation (Thèmes CSS)

L'une des forces du projet est l'utilisation des **Variables CSS** pilotées par React pour changer l'apparence instantanément sans recharger la page.

| Thème     | Description             | Couleurs Dominantes |
| :-------- | :---------------------- | :------------------ |
| **Light** | Classique et épuré      | Blanc / Gris clair  |
| **Dark**  | Confort visuel nocturne | Noir / Anthracite   |
| **Tech**  | Ambiance "Matrix"       | Noir / Vert Néon    |
| **Cyber** | Style futuriste         | Violet / Jaune Vif  |

---

## 🛠️ Stack Technique

### Front-end

- **React 19** (Hooks `useState`, `useEffect`, `useContext`)
- **React Router Dom v7** (Gestion de la navigation)
- **Vite** (Outil de build ultra-rapide)
- **CSS Moderne** (Variables `:root` et attributs de données `data-theme`)

### Back-end (API)

- **Node.js & Express**
- **MySQL** (Base de données relationnelle)
